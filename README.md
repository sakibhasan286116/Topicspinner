# Topic Spinner

A beautiful web app that spins random research topics from 1248+ topics across 16 subjects. Pick a subject, spin a topic, run a focused research session with a timer, and take notes.

## Features
- 1248+ research topics across 16 subjects
- Topic of the Day
- Focus timer (30/45/60 min) with guided research steps
- Notes & summary with word count and download
- Session history with count badge
- Modern dark UI with animated video background
